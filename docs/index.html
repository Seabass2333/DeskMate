🍎 macOS 首次打开提示「无法验证开发者」或「已损坏」怎么办？

因目前为独立开发者开源免费版本尚未购买 Apple 商业签名，将 DeskMate 拖入「应用程序」文件夹后，在终端执行以下一行命令即可正常打开：

xattr -cr /Applications/DeskMate.app
